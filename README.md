# Wii U Launcher
Welcome to the **Wii U–themed Launcher** repo!

## 🎮 Wii U Style Overview
This project now includes a Wii U-inspired launcher interface with:
- Wii U color palette and rounded panel styling
- Channel-style app tiles
- Footer status updates when channels are selected

## Run locally
Open `index.html` directly in a browser, or serve this directory with any static server.
